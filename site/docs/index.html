agentic-go Documentation

agentic-go is a local Go MCP server and CLI that equips external AI coding agents with source-grounded code intelligence, change continuity, guarded refactoring, and executed whole-package verification.

Why agentic-go?

General-purpose coding agents frequently struggle with Go codebases because:

  • Context Overload: Dumping whole files or huge compiler outputs into the LLM context window exhausts token budgets and degrades reasoning quality.
  • Intent Drift: Agents lose track of initial boundaries, inadvertently modifying exported API signatures, editing generated files, or breaking cross-package contracts.
  • Unverified Changes: Text edits often go untested or are only checked with narrow, cherry-picked unit tests that mask regression bugs or concurrency races.

agentic-go solves these problems by providing deterministic, local MCP tools backed by a pinned gopls companion and high-precision static analyzers.

Architectural Model

agentic-go operates strictly as a local stdio MCP server or a standalone CLI. It does not embed an LLM or act as an agent framework; instead, it acts as a high-precision toolchain assistant for external agents like Claude Desktop, Cursor, Cline, or Claude Code.

Key Principle: Immutable Snapshot Lineage

All semantic lookups, refactoring plans, and verification reports are anchored to content-addressed Snapshot Refs (sha256:...). If the underlying repository files change while an agent is thinking, stale operations fail closed rather than silently drifting.
