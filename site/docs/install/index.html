Installing agentic-go

agentic-go installs as a self-contained local binary bundle consisting of agentic-go, the pinned agentic-go-gopls companion, and agentic-go-vet.

Supported Environments

  • Operating Systems: macOS (Darwin) and Linux
  • Architectures: amd64 (x86_64) and arm64 (Apple Silicon / AArch64)
  • Go Toolchains: Go 1.25, 1.26, and 1.27
Pinned Gopls Companion

You do not need to install or configure gopls separately. The release bundle packages an exact, tested gopls v0.21.0 binary configured for private stdio LSP communication with telemetry disabled.

Method 1: Homebrew (macOS & Linux)

The recommended installation method uses our official Homebrew tap:

Terminal
$ brew install agentic-mcps/tap/agentic-go
$ agentic-go --version

Method 2: Standalone Shell Installer

For automated CI environments or systems without Homebrew, use the official shell installer. It verifies cryptographic checksums before writing binaries to ~/.local/bin:

Terminal
$ curl -fsSL https://raw.githubusercontent.com/agentic-mcps/go/v1.0.0/scripts/install.sh | bash -s -- 1.0.0

Validating Installation with doctor

Run agentic-go doctor inside any Go repository to verify your local Go toolchain, sidecar binaries, and environment compatibility:

Terminal
$ agentic-go doctor
> [PASS] Go toolchain: go1.27.0 darwin/arm64
> [PASS] Companion sidecar: agentic-go-gopls v0.21.0
> [PASS] Workspace: contained and symlink-safe
