Connecting MCP Clients

agentic-go speaks standard Model Context Protocol (MCP) over stdio. There are no ports to forward, daemons to manage, or external accounts required.

Generating Configuration Automatically

You can print ready-to-use configuration for your preferred client using the built-in mcp-config command:

Terminal
$ agentic-go mcp-config --client claude --workspace $(pwd)

Client Configuration Snippets

// ~/Library/Application Support/Claude/claude_desktop_config.json

{
  "mcpServers": {
    "agentic-go": {
      "command": "agentic-go",
      "args": [
        "--workspace",
        "/absolute/path/to/your/go/project"
      ]
    }
  }
}

// In Cursor Settings > Features > MCP > Add New MCP Server

{
  "mcpServers": {
    "agentic-go": {
      "command": "agentic-go",
      "args": ["--workspace", "${workspaceFolder}"]
    }
  }
}

// ~/Library/Application Support/Code/User/globalStorage/saoudrizwan.claude-dev/settings/cline_mcp_settings.json

{
  "mcpServers": {
    "agentic-go": {
      "command": "agentic-go",
      "args": ["--workspace", "/absolute/path/to/your/go/project"],
      "disabled": false,
      "autoApprove": []
    }
  }
}
$ claude mcp add agentic-go agentic-go -- --workspace $(pwd)

Server Parameters

Flag Default Description
--workspace <path> Current directory (.) Absolute or relative root path of the target Go module / workspace.
--timeout <duration> 45s Maximum timeout for semantic lookups and compilation passes.

Preflight Diagnostics

When the MCP server starts, it verifies the host toolchain before opening stdio communication:

  1. Checks that go is in PATH and satisfies Go 1.25+.
  2. Resolves workspace symlinks and validates directory containment.
  3. Spawns the bundled agentic-go-gopls sidecar, negotiates LSP capabilities, and disables gopls telemetry.
