GitHub Action Integration

The official composite GitHub Action provides zero-overhead change verification directly in pull request workflows.

Workflow Example

Add .github/workflows/verify-change.yml to your repository:

.github/workflows/verify-change.yml 
name: Verify Change

on:
  pull_request:
    branches: [main]

jobs:
  agentic-verify:
    name: Verify Impacted Packages
    runs-on: ubuntu-latest
    permissions:
      contents: read # Least privilege, no PR write permission needed

    steps:
      - name: Checkout Repository
        uses: actions/checkout@v4
        with:
          fetch-depth: 0 # Full history to compare against base branch

      - name: Set up Go
        uses: actions/setup-go@v5
        with:
          go-version: '1.27'

      - name: Run agentic-go Verification
        uses: agentic-mcps/go@v1.0.0
        with:
          base: ${{ github.event.pull_request.base.sha }}
          package: ./...
          race: true
          fail-on: error

Action Inputs

Input Default Description
version 1.0.0 The exact release version of agentic-go to download and verify against pinned checksums.
base origin/main The git base revision used to calculate the changed files and affected package closure.
package ./... Target package pattern. Impact analysis resolves all downstream dependent packages automatically.
race true Whether to run tests with the Go race detector enabled.
fail-on error Threshold that causes the GitHub Actions step to fail: error, warning, or findings.

Security & Permissions

The Action adheres strictly to least-privilege principles:

  • Read-Only Permissions: Requires only contents: read. It does not request or require pull request comment permissions or token write access.
  • Cryptographic Verification: The action downloads the official release tarball and verifies its SHA-256 digest against hardcoded release signatures before extracting binaries.
  • Native Job Summaries: Generates clean, accessible Markdown summaries directly in the GitHub Actions Job Summary view ($GITHUB_STEP_SUMMARY).
