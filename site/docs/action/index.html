GitHub Action Integration

The official composite GitHub Action provides change verification in pull request workflows.

Workflow Example

.github/workflows/verify-change.yml 
name: Verify Change

on:
  pull_request:
    branches: [main]

jobs:
  agentic-verify:
    name: Verify Impacted Packages
    runs-on: ubuntu-latest
    permissions:
      contents: read

    steps:
      - name: Checkout Repository
        uses: actions/checkout@v4
        with:
          fetch-depth: 0

      - name: Set up Go
        uses: actions/setup-go@v5
        with:
          go-version: '1.27'

      - name: Run agentic-go Verification
        uses: agentic-mcps/go@v1.0.0
        with:
          base: ${{ github.event.pull_request.base.sha }}
          package: ./...
          race: true
          fail-on: error

Security & Permissions

  • Least Privilege: Requires only contents: read. Does not require PR write permission.
  • Cryptographic Verification: Downloads the official release bundle and verifies its SHA-256 digest before execution.
  • Job Summaries: Generates native Markdown summaries directly in GitHub Actions summary output.
