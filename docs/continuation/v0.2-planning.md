# Superseded v0.2 planning handoff

This 2026-08-24 handoff originally proposed a plan-only MCP change-impact tool,
selective test reachability, and structured-test filtering. Product review
rejected that boundary before production implementation because it optimized a
protocol surface instead of a repeatedly useful developer workflow and could
overstate the soundness of selected tests.

The replacement is change verification with one portable report shared by the
CLI, GitHub Action, and MCP adapters. It executes whole-package checks for a
conservative affected closure, compares calibrated analyzer findings with the
base, reports changed-statement coverage, and states uncertainty explicitly.

This file is retained only as a truthful decision record. It is not an active
handoff or implementation authority. Read:

- [`../v0.2.0-release-scope.md`](../v0.2.0-release-scope.md) for the executable
  specification;
- [`../adr/0001-verification-report-boundary.md`](../adr/0001-verification-report-boundary.md)
  for the architectural decision; and
- [`../../CONTEXT.md`](../../CONTEXT.md) for the current domain language.
