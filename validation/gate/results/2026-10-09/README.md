# Gate evaluation results, 2026-10-09

Protocol: [`../../README.md`](../../README.md) (pre-registered, with Amendments 1–4).
Gate under test: `agentic-go` built from commit `7b1338d`. Harness: commit `273643f`.
Environment: Go 1.25.0, linux/amd64, 4 CPUs, run as root (see `environment.txt`).

## Verdict

The pre-registered kill criteria fail. `agentic-go check` does not catch hidden test
tampering better than a strong conventional gate, and it is clearly worse than a 60-line grep
script at it. By the protocol's own rule, the gate's integrity analysis does not justify a
product.

Where the gate misses, it is by design rather than by accident. Its rules were tuned for
precision: a skip behind an environment check, a test moved into a new build-tagged file, and
a skip inside a test the same change added are warnings, not blocks. Wrapping a test body in a
closure that is never called is not detected. Many cover-ups hide tests the change itself
added, which do not exist at the base, so "deleted" or "skipped" relative to the base does not
fire. A naive grep for added `.Skip(` calls and removed `func Test` lines has none of these
blind spots.

The precision engineering does buy something, but not enough to matter. On legitimate
destructive changes (real commits that delete or skip tests) the gate falsely blocked 37% vs
grep's 97%. On ordinary true patches outside testify the gate falsely blocked 6/120 (5%) vs
12/120 (B2\*) and 21/120 (B3), because failures that also occur at the base are attributed and
downgraded.

## Known gate defect found by this evaluation

22 of the gate's 28 false blocks on true patches are in testify. Its `suite` package runs inner
test suites through `testing.RunTests` that fail on purpose; `go test -json` reports those inner
failures as named test failures although the package passes. The gate re-runs each named
failure with `-run '^Name$'`, finds no such test at the base, and treats it as a new failing
test. B2\* is not affected because the same phantom failures appear at the base and are
subtracted. Fix: ignore named failures inside a package whose overall result is a pass, or
attribute by comparing the full failure sets as B2\* does. The reported numbers use the frozen
binary with this defect; excluding testify, K3 still fails (6/120 = 5%).

## Disclosures and deviations

- **D1–D5 are not held out.** The reviewer of the integrity checks was given their descriptions
  and the detector was changed afterwards (Amendment 1). They are reported as "seen".
- **D6–D10** were generated by a program written by an agent that did not read the gate, this
  protocol's variant list, or the D1–D5 generator. After they were written the controller froze
  the integrity rules. One later reviewer independently noticed the uncalled-closure blind
  spot (D10); it was not fixed before the run.
- **Amendment 2** strengthened B2\* (base vet failures ignored, `go test` timeouts block, paired
  comparisons). **Amendment 3** made B2\* ignore lint issues present on the unmodified commit,
  after a five-variant pilot. **Amendment 4** gave every lint run a fresh cache after the shared
  cache was found to return stale results. All three make the baselines stronger or more
  deterministic. Pilot runs are excluded.
- **Disk exhaustion.** The run stopped at 658 of 821 variants when the session's disk allowance
  ran out. Every run of the 26 variants recorded within 150 lines of the first disk-related
  error was discarded, caches written in the preceding hour were deleted, and those variants
  were re-run. No run in the final data mentions a disk error.
- **Quotas.** True patches 150 of 150; flaw seeds 50 of 50 (41 produced a killing mutant);
  destructive true patches 38 of the 100 allowed (only 38 qualified). S2 (consumer break, n=1)
  and S3 (dropped error check, n=3) are too small to interpret.
- **Selection skew.** 223 candidate commits were excluded because their dependencies no longer
  download; the corpus skews toward recent history.
- **Synthetic flaws.** These variants measure the detectors. They say nothing about how often
  real agents tamper with tests, or whether a gated agent ships better code.
